# GreenLeaf Markets Sales Performance Analysis

## Project Overview
An end-to-end data analytics project analyzing 10,195 rows 
of retail sales data to identify profitability issues and 
provide actionable business recommendations.

## Tools Used
- Microsoft Excel — Data cleaning and Pivot Table analysis
- SQL — Database querying and validation
- Tableau Public — Interactive dashboard

## Business Questions Answered
1. Which Sub-Category has highest Sales but lowest 
   Profit Margin?
2. How have Sales changed year over year across Regions?
3. Does higher Discount lead to lower Profit?

## Key Findings
- Chairs generate highest sales but only 4.71% 
  profit margin
- Central region has -10% average profit margin
  despite positive total profit
- 1,370 loss making orders linked to excessive 
  discounting
- Binders most frequently appear in loss making orders

## Recommendations
1. Cap discounts on Binders at maximum 15%
2. Conduct pricing audit of Central region
3. Invest additional resources in East region growth
